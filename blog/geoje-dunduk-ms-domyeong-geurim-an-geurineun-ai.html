도형 문제를 머릿속으로만 풀다 틀린다면, 문제에 나온 조건을 하나씩 그림에 옮겨 적는 습관부터 들이는 것이 가장 효과적이에요. 문제에 그림이 주어져 있어도 길이·각도·평행 같은 조건을 그림 위에 직접 표시해야 보이지 않던 관계가 보여요. 둔덕중학교 학생이 도형 단원에서 자주 막힌다면 '그림에 쓰기'를 풀이의 첫 단계로 정해 보세요.

한눈에 보기
  • 그림이 없으면 직접 그리고, 있으면 조건을 옮겨 적기
  • 같은 길이·같은 각·평행은 기호로 표시
  • 구하는 것에 물음표
  • 그림은 크게, 자는 없어도 괜찮아요

그림에 표시할 것

문제의 조건그림에 표시하는 법
길이가 같다같은 개수의 짧은 빗금
각의 크기가 같다같은 모양의 호 표시
평행하다두 선분에 같은 방향 화살표
직각이다작은 네모 표시
구하는 것물음표나 x

이렇게 표시하면 문제를 다시 읽지 않아도 그림만 보고 풀이를 이어 갈 수 있어요.

그림 그리는 순서

  1. 크게 그리기 — 작게 그리면 표시할 자리가 없어요. 연습장 반쪽 정도 크기로 그려요.
  2. 문제를 한 문장씩 읽으며 표시 — 조건을 읽을 때마다 바로 그림에 옮겨요.
  3. 구하는 것 표시 — 마지막에 무엇을 구하는지 물음표로 적어요.
  4. 표시한 것끼리 관계 찾기 — 같은 표시가 있는 곳, 직각이 있는 곳에서 쓸 수 있는 성질을 떠올려요.

학습 예시: 이등변삼각형 문제

아래는 그림 표시 방법을 보여 주려고 만든 예시 문제예요.

예시 문제) 삼각형 ABC에서 AB = AC이고 ∠A = 40°일 때, ∠B의 크기는?

  • 그림: 삼각형을 그리고 AB와 AC에 빗금 하나씩 → 두 변이 같다는 표시
  • ∠A에 40°라고 적고, ∠B에 물음표
  • 빗금을 보고 '이등변삼각형의 두 밑각은 같다'를 떠올리기 → ∠B = ∠C에 같은 호 표시
  • 세 각의 합 180°: ∠B + ∠C = 140°, 그래서 ∠B = 70°

그림에 빗금을 그려 두면 '두 변이 같으니 두 각도 같다'는 생각이 자연스럽게 이어져요.
